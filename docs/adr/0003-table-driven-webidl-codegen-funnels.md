# Table-driven WebIDL codegen with shared funnels

`webidl-bindgen` emits static member tables and shared `#[inline(never)]` conversion, custom-element reaction (`reactions::enter`/`reactions::finish`), reflection (`host::ReflectBinding`/`host::reflect_dispatch`), and interface-installation funnels monomorphized per IDL type rather than per member, and resolves `[SecureContext]` exposure once in the IDL database for both native and JS emitters. Reflected attributes (including enumerated attributes over static `Enumerated::KEYWORD_STRS` slices) live as pure static data on `host::MemberKind::Attribute`, omitting `dispatch` entirely on reflection-only partial interfaces, while dictionary conversions still deserialize unused members so WebIDL type errors fire on invalid present properties without hand-written glue.
